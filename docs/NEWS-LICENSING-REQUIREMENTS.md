# News licensing requirements

No licensing conclusion is made from technical API access. Before live staging calls, record the account plan, permitted endpoints, redistribution/display rights, attribution requirements, full-content/image/storage rights, retention/cache limits, geographic limits, rate/credit limits, delay, archive range, and expiry.

Required independent states: `LICENSE_VERIFIED`, `SECURITY_APPROVED`, `COMPLIANCE_APPROVED`, `CREDENTIAL_OWNER_AUTHORIZED`, and `STAGING_APPROVED`. They are currently absent. Archive is omitted operationally until explicit entitlement exists.
