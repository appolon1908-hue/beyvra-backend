# Disaster-recovery evidence

`latest/` is generated by the isolated verifier and contains only a checksum, parsed archive manifest, restore stderr, reconciliation output and key/value results. Database dumps and secrets are intentionally excluded from version control.

Certification is evidence-driven: an absent result is `NOT_TESTED`, never an implicit pass. The repository-only drill does not certify a live staging host rebuild, frontend E2E, realtime gap recovery, deployment rollback, migration rollback, Prometheus/Grafana runtime state, dependency/container vulnerability thresholds, encryption-at-rest, or PITR.
