# Disaster-recovery evidence

`latest/` is generated by the isolated verifier and contains only a checksum, parsed archive manifest, restore stderr, reconciliation output and key/value results. Database dumps and secrets are intentionally excluded from version control.

Certification is evidence-driven: an absent result is `NOT_TESTED`, never an implicit pass. The disposable drill certifies backend host reconstruction, PostgreSQL restore, migration-failure recovery, outbox/inbox recovery, Redis loss, NATS/JetStream restart, configuration rollback, and simulation plus `/ws/v2/` contract E2E. It does not certify a browser runtime, live staging image rollout, measured frontend gap recovery, Prometheus/Grafana runtime state, encryption at rest, or PITR.
