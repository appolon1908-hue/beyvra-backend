# Provider capability matrix

Review date: 2026-08-11. This matrix records vendor capability from current official documentation; it does not establish Beyvra entitlement, redistribution rights, or approval. All Beyvra entitlement and approval fields remain `NO` until independently evidenced.

| Provider | Authentication | REST / history | WebSocket / realtime | Data and asset classes | Limits, timing, reconnect | Beyvra entitlement |
|---|---|---|---|---|---|---|
| CoinGecko | Pro key in `x-cg-pro-api-key`; backend header is recommended | Coin/reference, prices, markets and OHLC; endpoint access and update frequency vary by plan | Vendor offers WebSocket/webhook products; access is plan-dependent | Crypto and on-chain reference/market data | Minute and monthly credits are plan/key-specific; even failed calls consume minute rate-limit capacity. Public tier requires backoff on 429. Provider timestamp precision varies by endpoint. | NOT VERIFIED; REST/WS NOT AUTHORIZED |
| Massive / Polygon | API key; WebSocket authenticates after connect | On-demand realtime/historical trades, quotes, aggregates, snapshots and reference products | Separate delayed and realtime clusters; trades, quotes, minute/second aggregates, and selected LULD feeds | Stocks, options, futures, indices, forex and crypto, varying by product | Common default is one concurrent WebSocket per asset class; slow consumers may be disconnected. Entitlement determines delayed versus realtime. Timestamps are documented per feed, commonly Unix ms for trade/aggregate events. Reconnect/resubscribe is client responsibility or official-client behavior. | NOT VERIFIED; REST/WS NOT AUTHORIZED |
| NewsData.io | API key | Paginated news/search; credit use and result size depend on plan | No approved Beyvra streaming adapter | News only; never trading authority | Credit/rate limits vary by subscription and page retrieval consumes credits. Redistribution is governed by vendor terms. | NOT VERIFIED; NEWS DISABLED |
| Alpaca market data | `APCA-API-KEY-ID` and `APCA-API-SECRET-KEY` | Historical/reference market-data APIs | `wss://stream.data.alpaca.markets/{version}/{feed}`; stocks, crypto, options and news | Market data is separate from trading; feed availability depends on subscription | Authentication rejects unavailable feeds. Connection limits are subscription-specific and commonly one per endpoint. Provider timestamps are feed-specific. Reconnect and resubscribe must be bounded. | NOT VERIFIED; REST/WS NOT AUTHORIZED |
| Alpaca paper | Same credential family, paper hostname | Paper account/order APIs | Paper trade/account/order update stream | Simulated execution only | Paper fills are simulations and do not establish live-routing certification. | NOT AUTHORIZED; `ALPACA_MODE=PAPER` not activated |
| Binance / Twelve Data / CoinCap / Fixer | Adapter-specific | Existing code inventory only | Existing Binance/Twelve Data capability where implemented | Crypto, equity and FX subsets | Fixture-only budgets/backoff; plan and license unverified | NOT VERIFIED; DISABLED |

Official sources: [CoinGecko authentication](https://docs.coingecko.com/reference/authentication), [CoinGecko endpoint plans](https://docs.coingecko.com/reference/endpoint-overview), [Massive REST quickstart](https://massive.com/docs/rest/quickstart), [Massive WebSocket quickstart](https://massive.com/docs/websocket/quickstart), [Alpaca market-data stream](https://docs.alpaca.markets/docs/streaming-market-data), [Alpaca paper trading](https://docs.alpaca.markets/docs/paper-trading), and [NewsData credit behavior](https://newsdata.io/blog/newsdata-credit-consumption/).
